# Paquete de entrega al adquirente

Documentación operativa de PowerPOS Pioneers, versión 1.2, actualizada el 17 de septiembre de 2026. Paquete reutilizable para varias empresas, comenzando por un piloto en una empresa. El sistema no está desplegado todavía.

1. [Manual ilustrado y detallado](manual-operacion-detallado.md): instrucciones por pantalla y rol, campos, ejemplos, resultados y resolución de problemas. [Guía breve](manual-del-cliente.md).
2. [Acta de entrega y aceptación](acta-de-entrega.md): datos de implantación, alcance, pruebas, capacitación y responsables.
3. [Soporte y mantenimiento](soporte-y-mantenimiento.md): procedimiento para incidentes y responsabilidades por acordar.
4. [Procedimientos operativos](procedimientos-operativos.md): ventas inciertas, correcciones, arqueo, inventario, contingencia y recuperación.
5. [Plan piloto y capacitación](plan-piloto-y-capacitacion.md): fases, ejercicios por rol, métricas y criterios de ampliación.
6. [Alcance y ficha por empresa](alcance-y-ficha-por-empresa.md): módulos a contratar y condiciones por implantación.
7. [Informe de validación](informe-validacion.md): pruebas ejecutadas, resultados y bloqueos pendientes.

Versiones imprimibles: [manual ilustrado](../entregables/manual-del-cliente.html), [guía del piloto y entrega](../entregables/guia-piloto-y-entrega.html) y [acta](../entregables/acta-de-entrega.html). Las capturas están incluidas en el HTML para lectura sin conexión.

El proveedor debe completar datos de contacto, URL, versión desplegada y capacidades antes de entregar este paquete como definitivo. Las firmas y pruebas están pendientes. El manual no ofrece como operativas funciones futuras o integraciones sin verificar.

Los documentos técnicos, requerimientos y diagramas están en el [expediente del proyecto](../README.md). No incluir archivos `.env`, cuentas demo, tokens ni respaldos con datos personales en el paquete enviado al comprador.
